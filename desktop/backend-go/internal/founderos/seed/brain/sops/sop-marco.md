# Run discovery & close calls

## Purpose

The human on the phone from hello to signed.

## Owner

[[person-marco]] — one worker, one job (monogamous by design).
Runs on: human · judgment call.

## Trigger

Kicks off when it is time to "review the pre-call brief and the lead’s last three touches" — on cadence or on the upstream event, whichever lands first.

## Steps

1. Review the pre-call brief and the lead’s last three touches
2. Run the discovery script and qualify hard on budget and timeline
3. Handle objections with the objection sheet, never improvise pricing
4. Present the matching offer and the financing option when it fits
5. Log the outcome, next step and payment link before the next call

## Definition of done

The run is complete when "log the outcome, next step and payment link before the next call" has verifiably happened and is logged to the run history.

## Escalation

If any step fails twice in a row, or the data looks wrong, stop and escalate to the operator. Never fake a green run.
