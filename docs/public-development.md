# Public Development History

BusinessOS publishes verified open-source changes to this repository as public commits.
Each update preserves the previous public commits, so you can browse the history and compare changes over time.
Updates identify the product areas that changed, and their diffs show the exact source changes.
Unchanged public source does not create an empty update.

## Source And Privacy

The public edition is built from a filtered projection of the canonical source repository.
Private workspace data, internal delivery material, production deployment workflows, and commercial-only components are not part of that projection.
Publication checks the public product boundary, compiles the projected backend, and builds the projected frontend before publishing.
Public commits are linked only to reviewed public history, never to private repository commits.

## History Baseline

The September 28, 2026 sanitized snapshot is the baseline for continuous public history.
Earlier publishing replaced the public branch with a new single-commit snapshot on each sync.
That process removed private ancestry but also erased the visible progression of public updates.
History is retained from this baseline onward; older development activity is not reconstructed or backdated.
An update reflects committed, verified source changes, not every unfinished local edit or every production deployment.
