# YouTube / Media Learning Import Prompt

Use this when I want to save a video, transcript, lecture, podcast, or media
source into an Optimal Engine learning or research workspace.

## Goal

Preserve the source, extract useful learning context, and create reviewable
memory without treating a transcript or summary as automatic truth.

## Inputs

I may provide:

- YouTube URL
- video file
- audio file
- transcript
- notes
- playlist
- topic or learning goal

## Your Job

1. Identify the Workspace and Learning/Research Node.
2. Preserve the URL/file/transcript as source evidence.
3. Pick the right tool surface:
   - transcript API/provider
   - browser/MCP tool
   - CLI downloader/transcriber where allowed
   - local transcription adapter
   - manual transcript import
4. Extract title, source URL, creator/channel, date if available, transcript or
   summary, key ideas, open questions, and follow-up reminders.
5. Create pending Claims only for durable lessons that should be reviewed.
6. Suggest tags, related Nodes, and review cadence.

## Output

Return:

1. Source inventory.
2. Suggested Node placement.
3. Tool surface recommendation.
4. Extracted learning notes.
5. Pending Claims for review.
6. Follow-up reminders.
7. Any copyright/licensing or access concerns.
